The gateway is reachable inside the cluster at:

  http://{{ include "llm-gateway.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}/v1/chat/completions

To try it from this machine:

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "llm-gateway.fullname" . }} {{ .Values.service.port }}
  curl http://127.0.0.1:{{ .Values.service.port }}/readyz

The gateway serves plain HTTP and the Service is ClusterIP only. Put TLS in
front of it before exposing it outside the cluster. The metrics port ({{ .Values.service.metricsPort }}) is
unauthenticated; limit who can reach it on the pod network.

The pods check the database schema at startup but never migrate it. Run
`gateway migrate` with the same image and database URL before the first
install and after upgrades that add migrations.
